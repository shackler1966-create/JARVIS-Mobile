J.A.R.V.I.S MOBILE — إصدار 2.0 بدون Picovoice

ما الجديد؟
- أزلنا اعتماد Picovoice بالكامل؛ لا تحتاج إلى حساب Picovoice أو AccessKey.
- لا توجد كلمة تنبيه تعمل دائماً في الخلفية في هذا الإصدار.
- اضغط زر «TAP TO TALK TO JARVIS» عندما تريد التحدث. يبدأ Android التعرف على الكلام عند الضغط فقط.
- يمكنك أيضاً كتابة الأمر ثم الضغط على SEND TEXT COMMAND.
- الردود الذكية تستخدم OpenAI API، ويقرأها محرك تحويل النص إلى كلام المثبت في Android.

بناء APK عبر GitHub من الهاتف:
1. استبدل ملفات المشروع في مستودعك بهذه النسخة، أو ارفع محتويات هذا المجلد إلى جذر المستودع.
2. نفّذ git add . ثم git commit -m "JARVIS no Picovoice tap to talk" ثم git push.
3. افتح GitHub > المستودع > Actions.
4. افتح أحدث تشغيل لسير العمل Android. انتظر حتى تصبح النتيجة Success.
5. افتح التشغيل الناجح، ثم قسم Artifacts، ونزّل JARVIS-debug-APK.
6. فك ضغط ملف Artifact إذا نزّله GitHub كملف ZIP، ثم ثبّت app-debug.apk على الهاتف.

إعداد التطبيق:
1. افتح JARVIS Mobile.
2. أدخل مفتاح OpenAI API الخاص بك واضغط SAVE API KEY ON THIS PHONE.
3. اسمح بإذن الميكروفون عند طلبه.
4. اضغط زر الميكروفون وتحدث. يمكنك استخدام العربية أو الإنجليزية حسب إعداد التعرف على الكلام في هاتفك.
5. لا ترسل مفتاح API إلى أي شخص ولا تضعه في GitHub.

أوامر الهاتف المضمنة:
- افتح واتساب
- افتح يوتيوب
- افتح الكاميرا
- ارفع الصوت
- اخفض الصوت
- اقرأ الإشعارات (بعد تفعيل صلاحية الوصول إلى الإشعارات يدوياً)
- اتصل [اسم جهة الاتصال] (يفتح شاشة الاتصال للمراجعة ولا يجري الاتصال تلقائياً)

قيود مهمة:
- هذا الإصدار ليس استماعاً دائماً؛ يجب الضغط على زر الميكروفون في كل مرة. لا يمكنه سماع كلمة «Jarvis» والهاتف مقفل.
- التعرف على الكلام قد يستخدم خدمة Google أو مزود التعرف على الكلام في الهاتف، وقد يحتاج إلى الإنترنت.
- يحتاج الذكاء الاصطناعي إلى مفتاح OpenAI API وفوترة API فعالة إن تطلب حسابك ذلك. اشتراك ChatGPT لا يتضمن تلقائياً رصيد API.
- المفتاح محفوظ محلياً في تفضيلات التطبيق الخاصة، لكن تطبيقاً إنتاجياً ينبغي أن يستخدم خادماً وسيطاً آمناً بدلاً من وضع المفتاح داخل التطبيق.
- قراءة الإشعارات ميزة حساسة؛ فعّلها فقط إذا كنت تريد أن يقرأ JARVIS نصوص إشعاراتك.
- عينة الصوت المسجلة سابقاً ليست مدمجة في هذا الإصدار؛ الردود تستخدم صوت TTS المتاح على Android.

المتطلبات:
- Android Studio / Android SDK 35
- Java 17
- Android Gradle Plugin 8.7.3
- Kotlin 2.0.21
