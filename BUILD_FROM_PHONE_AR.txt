طريقة البناء من الهاتف عبر GitHub Actions:

1) افتح مستودع JARVIS-Mobile في GitHub.
2) ارفع واستبدل ملفات المشروع بهذه النسخة (مجلد app وملفات Gradle وملفات .github).
3) من تطبيق Termux داخل مجلد المشروع نفّذ:
   git add .
   git commit -m "JARVIS no Picovoice tap to talk"
   git push
4) في GitHub افتح تبويب Actions.
5) افتح أحدث تشغيل باسم Build JARVIS APK.
6) انتظر حتى يظهر Success.
7) انزل إلى Artifacts واضغط تنزيل JARVIS-debug-APK.
8) افتح ZIP الذي تم تنزيله واستخرج app-debug.apk.
9) اضغط APK لتثبيته، واسمح بالتثبيت من هذا المصدر إذا طلب Android ذلك.

مهم: لا تكتب كلمة مرور GitHub عند طلب كلمة المرور. استخدم GitHub Personal Access Token أو تسجيل الدخول عبر GitHub CLI. لا تشارك الرمز مع أحد.
